## 一、923 md 的骨架（总结）

### 1. 三个 Stage 各自只做一件事
| 阶段 | 输入 | 必须完成 | 明确不做 |
|---|---|---|---|
| **Stage1** 抓取能力与配方 | 规范初态、物理 profile、MANO 参考、候选或已有 artifact | 固定位姿闭合/稳定 → 独立提升测试 → **验证并交付可靠配方** | 不做接近/搬运；不隐式重复搜索 |
| **Stage2** 接近与首段搬运 | 通过合同的 Stage1 artifact（同 profile） | **连续接近 → 复用闭合/稳定 → 参考搬运** | 不 reset 目标；不 set_pose 纠正；不重生成曲线 |
| **Stage3** 剩余任务与最终验收 | 通过 Stage2 的完整 bundle | 完成剩余搬运（可选释放）→ **再独立重放** | 不把 Stage2 重放当 Stage3 完成 |

帧号语义分开 ✓：`source_frame` = 候选来自哪个 MANO 帧（s31 = **65**，保留并追溯）；
`task_grasp_frame` = 原任务抓取时刻（当前 **F50**）；`control_index` = 实际控制序号。
**闭合增加控制点不改变原任务抓取帧**；F62 只有在任务确实以 F62 结束时才是整任务终点。

### 2. 只允许三种执行语义（md §2.1）
| 语义 | 含义 |
|---|---|
| `command_transfer` | 沿新接近/搬运轨迹，按获胜 anchor **复用实际 close/settle 命令**；近期可交付基线，**不宣称自适应** |
| `feedback` | 冻结同一控制 spec，由同一控制器按当前观测产生命令；q 与闭合时长可因观测改变，**必须记录实际执行** |
| `strict_replay` | 从规范初态消费整条已成功任务的**实际 T/q/t**；反馈只监测保护，不重新插值/改 q/改频率 |

⚠ 现状：代码里**没有**这套分流；一个 `q_override` 标量不等于整条冻结轨迹。

### 5. 交付合同与判据口径（md §5）
- **身份**：candidate_id、episode_id、source_frame、task_grasp_frame、模式、schema、代码/控制器/物理/判据 hash ✓
- **命令**：同长 N>0 的 `time_s` / `T_W_G_cmd`(N×4×4) / 公共 q 与实际映射后的 `q_cmd` / `phase` / `control_index` / `source_phase`；有限值、旋转合法、时标递增 ✓
- **相位**：半开区间 `[start,end)`，从 phase 推导；close/settle 计数、兼容字段、总长**一致** ✓
- **Stage1 判据**：保留旧证书；v2 用**实际载荷 / 目标离桌 / 相对稳定**；**挡停率（旧"真夹持率"）只作诊断**，新旧并列核验
- **相对误差**：固定 C0，统一 **5mm / 5°**；不在 Stage3 放宽；与 MANO 偏差**分开报告**
- 已知时间量：130 点 close @30Hz ≈ **4.33s**，10 点 settle ≈ **0.33s**（解决停顿要先区分寻接触/预紧/稳定与额外空等，**不能因 q 重复删物理时间**）

### 6. 失败后只走一条路线（md §6 摘要）
| 失败 | 回到 | 禁止 |
|---|---|---|
| 缺 artifact / 坏 schema / 错 episode | 01 或 04 | 自动调用 Stage1 搜索 |
| profile / 观测 / **碰撞通道 UNKNOWN** | **02**（零物理反例先修） | 继续长搜索；把 UNKNOWN 写成 0/True |
| 冻结命令被改、相位 q 跳变 | 03 / 05（dispatch spy 定位） | 调摩擦掩盖调用错误 |
| 接近碰撞 / ready 失败 | 06 | 接触后瞬移、额外长时间张开空等 |
| CARRY 相对误差 | 06（重算实际矩阵与首失败索引） | 因日志数字相同就认定同一根因 |
| 同类失败两次修订无改善 / 预算耗尽 | 报首失败+已排除项+**一个**建议动作，请求方向 | 第三轮同类长扫描、另开进程刷 |

## 三十一、段边界姿态跳变（md:36 的 P0 插队项）核实 + 实测证伪（2026-10-03）
