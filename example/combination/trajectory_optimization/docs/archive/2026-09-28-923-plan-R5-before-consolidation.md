## A. 目标、边界和本次实质修订

### A.1 唯一目标

在当前真实夹爪、CoACD动态目标和桌面上，从预处理MANO轨迹连续接近，形成有承载能力的夹持，沿参考运动搬运，并保存可重放记录。对不同物体使用同一套执行规则，不靠每个物体手调偏移/摩擦/PD。先完成当前目标，再验证跨物体鲁棒性。

- Stage0保持不动。F35～F55仍是候选来源，F50仍是默认任务抓取时刻；来源帧与任务时刻分开。
- 保留CoACD分片、真实指形及目标—桌面/夹爪—桌面碰撞；其他物体干扰暂时隔离。不能靠box替换、绑定物体、接触后瞬移、放宽门或改质量来制造成功。
- test8及历史成功代码只提供参考，不作为必须完全复刻的前置项目。已通过且配置不变的Stage1不因普通Stage2路径修改而重跑。
- 夹爪按真实机构的公共开合自由度控制，不能因URDF有两关节就偷偷赋予独立指运动能力。
- 默认只允许原参考附近的局部修正；当前预算内不可行要报告需要的额外自由度，不自动扩大MANO偏差。
- **先交付可工作的执行链，再优化成功率，不继续无边界地追加诊断或参数扫描。** 每个失败必须进入G节指定的下一步。

### T03 — 共享接触反馈执行器：从“估算终点”改成“主动建立夹持”【TODO】

**闭合和预紧的具体规则：**

- 公共q的符号、上下界从本模式URDF/FK获得；当前gripper-only约定q减小闭合，但不硬套其他模式。两指命令由同一公共q映射。

- “双侧近接触”可允许一次≤0.2mm的低速试压，用于从轻触建立力；必须有有效采样、双方当前近接触证据和安全几何，不能用缺测启动。试压仍计入总预紧预算；没有产生真实双侧载荷不能进SETTLE。
- PRELOAD/SETTLE根据**实际左右法向力**调节q；低于载荷带缓慢闭合，高于上限有限退让，禁止无限积分。任一指超载、明显穿透或目标扰动超界优先保护，不能一味追求较弱一侧力。

- q反馈速度可采用带死区的比例规则，输出限速；增益先用固定候选小载荷响应标定，所有物体共用增益，不逐对象调PD。q压入预算不足以达到载荷时返回LOAD_UNREACHABLE，不静默加预紧/力限。

### E.2 成功判据criteria_v2

先分`INVALID / VALID_FAIL / PASS`。INVALID包括采样缺失、物理profile失配、非法穿透/越界、碰撞矩阵异常；不能进入成功候选排名。

PASS必须同时满足：真实左右指对目标形成持续受力；建议稳定与提升保持窗口分别至少80%的物理子步为双侧有效承载（作为新判据显式验证）；实际提升≥3cm（数值容差单列）；最终目标不由桌面支撑；无夹爪真实桌面阻挡、明显穿透或弹射；Stage1漂移≤20mm；Stage2沿用5mm/5°和完整搬运进度。

桌面状态同时看实际接触载荷、目标几何离桌和末端状态，不仅看contact列表。左右载荷、接触区域及力矩可行性应与任务运动自洽；80%是候选阈值，不代替实际提升。保留旧“挡停率≥50%”结果作旁路报告，**不再要求关节必须偏离命令1mm才能成功**。任何新旧门冲突都记录，不把旧指标直接删掉隐藏差异。

### E.3 统一短探针评分，不用奖励代替成功

沿用历史3.2节`ρ(x)=sqrt(1+x²)-1`及`J_rel/J_lift/J_contact/J_table/J_delta`定义，但旋转误差统一用`Log(R_refᵀR)`范数，单位rad；`J_delta`中的预紧项替换为`((α_load-1.5)/0.5)²`。其它归一化尺度保持5mm/5°/30mm、`Ns=mg/2`。

```text
J = 4*J_rel + 2*J_lift + J_contact + 2*J_table + 0.05*J_delta
R = -J
```

各项只读T01同一批ObservationFrame。完成短探针者以固定LIFT+HOLD窗口比较，不以“更早终止所以平均误差更小”取巧。有效但未形成夹持/提前安全终止者记录独立`VALID_FAIL`，缺少的提升/保持时段按冻结的固定失败代价报告，不能按短前缀均值与完整候选混排；失败代价值及归一化在首次实现中固定并写入criteria。T05保留有效失败作改进起点，但T07只交付满足PASS者。

## G. 遇到问题时怎么继续、何时提醒用户

以下规则用于后续已经获授权的实施工具；本文不是对外发消息、后台监控或改远端仓库的授权。提醒先写终端/当前对话及本轮报告，不操作其他应用。

| 事件 | 工具可继续做的事 | 必须停止/提醒的边界 |
|---|---|---|
| 单位、缩进、错误getter、导入未调用、数组错配 | 给出最小反例，修对应任务及生产入口回归，保留原失败证据 | 不因此改物理参数或成功门 |
| profile无效、接触统计越界、观测缺失 | 阻断下游，修T00/T01/T02 | 不把INVALID当0力后继续长搜索 |
| 一个几何有效候选抓不住 | 在T06固定预算内换候选/局部参数，保留最优有效解 | 超预算、全部不可行时停止，不递归重试 |
| 相同失败类型连续2次修订仍无改善 | 输出首失败时刻、反例和已排除项，建议一个明确替代动作 | 不开始第3轮同类长实验；请求用户确认方向 |
| 需要扩大±3mm/±1°、改变F35～F55范围、改Stage0 | 量化至少需要的变化及理由，提出选项 | 用户确认前不执行 |
| 需要改摩擦/质量/驱动力上限、碰撞形状/桌面过滤、成功门 | 给出原值/新值/依据/影响及新revision | 不能以“临时试一下”混入正式成功报告 |
| 物体弹射、严重穿透、力/速度超界 | 安全终止当前rollout，保存首次异常前后的轨迹 | 不继续硬夹或靠重新置位遮掉异常 |
| 即将耗尽任务预算或运行显著慢于预计 | 报已完成调用数、单次耗时、剩余预算及可用结果 | 未获确认不自行扩大预算或另开并行进程 |

每个任务开始先报：任务ID、将改文件、验收方法、预算；进行中至少每60秒简报进度（长仿真由runner输出心跳）；结束给`VERIFIED/BLOCKED`及证据。只有需用户决策时暂停其他依赖任务，能继续的只读核查或独立已授权任务可以继续。

统一失败报告字段：`task_id, revision, episode_id, first_failure_phase/control/time, expected, observed, valid, root_cause_confirmed_or_hypothesis, attempted_fix, next_action, needs_user_decision`。成功与失败都保存，不清理用户现有目录，不覆盖历史成功产物。

## 1. Stage1：固定四步，不再增加其他默认分支

### S1-A：21帧，每帧一次统一的夹取测试

输入为已经完成原有平移处理的F35～F55位姿 `T_i`。**不再次按物心平移，不生成每帧27个偏移点，不重新采样旋转。**

所有帧使用同一目标落稳状态、物理参数、驱动参数、桌面碰撞及测试动作：

```text
开放夹爪就位 → 低速闭合 → 1mm有限预紧 → 稳定0.5s
             → 1.0s平滑抬升3cm → 保持0.3s
```

这是粗筛短探针，不是完整Stage1验收。必须实际抬一下，才能区分“碰到了”与“有能力夹住”；只看物心距离或闭合对称不能回答这个问题。

闭合公共q速度≤5mm/s；建立真实双侧接触后预紧速度≤2mm/s。实际q超出URDF行程、初始化交叠、明显穿透、弹飞或观测缺失标为INVALID；不靠大力硬顶过这些问题。单侧接触后的额外公共q推进最多2mm；到上限仍无双侧，记录UNILATERAL而不是假报夹住。

采用第3节同一个连续奖励 `R=-J`。剔除物理无效样本后按R降序取 **3个不同源帧**，不增加“均匀分布帧号”或其他与得分冲突的选帧规则。同分按较小物体扰动、再按帧号排序即可。有效帧不足3个则使用实际数量；21帧都没有目标接触时返回NO_CONTACT_SEED，停止优化并查行程/对齐，不能在无接触平坦区无限求导。

输出 `stage1_screen.csv`，21帧均有一行：

```text
source_frame, pose, reward, left/right_normal_force, simultaneous_contact_ratio,
lift_final, relative_translation/rotation, table_support, valid, failure_reason
```

### S1-B：三个初值分别做同一种局部梯度优化

本版不再要求“先一维、再三维、再换一套优化器”。三个初值分别进入同一个 **7维有界L-BFGS-B**：

| 变量 | 初值 | 本版边界 |
|---|---|---|
| 抓取中心平移Δpx/Δpy/Δpz | 0 | 每轴±3mm |
| 局部旋转向量Δθx/Δθy/Δθz | 0 | 每分量±1°，总转角最多约1.73° |
| 公共闭合预紧δq | 1mm | 0.5～2mm，同时受真实剩余关节行程约束 |

这是针对上一版“只调闭合、不一定精修位姿”的明确修订：**本版会优化位置、旋转和闭合，但只在每个原始帧周围小幅修改。** 原有MANO总约束仍保留，边界与其取交集；不因本表允许±3mm就突破已有硬约束。质量、摩擦、PD、力上限均不属于优化变量。

以抓取中心为旋转支点，避免旋转顺带移动指腹：

```text
R = Exp([Δθ]×) R0                       # Δθ用弧度代入
p_grasp = p_grasp0 + Δp                 # Δp固定采用world坐标
p_base = p_grasp - R*r_base_to_grasp
```

`r_base_to_grasp`来自当前夹爪同一TCP定义，不用物体COM临时代替。若项目已有等价的TCP转换函数，直接复用。

每个初值先固定自己的闭合参考模板、q_touch参考、相位时刻和控制点数量。正负参数扰动只修改T和q终点，用相同时长的曲线重参数化；**不在每次扰动中重新触发不同长度的闭合状态机，也不重新按bbox生成q**。限速覆盖全部相位边界。改变δq后若超出行程，应在参数边界处理，不能偷偷clip后仍按未裁剪参数求导。

优化仍使用S1-A的3cm短探针和第3节奖励，不在每次求导里跑完整Stage2。每个初值始终保留“原始参数”和“最好有效参数”，优化器失败不能覆盖掉原有较好解。

### S1-C：正式验收三个最终候选

三个初值各交出一个最高分的有效候选。按照优化后的R排序，对候选冻结实际命令，做独立reset后的完整Stage1验证：

```text
开放就位 → 同一闭合/稳定配方 → 正式竖直20cm命令（4.5s）→ 末端观测
```

每个候选重复3次，三次必须同一份T/q/时间线；不能一边验证一边重新生成闭合。最多9次完整验证，不在失败后再采样或重跑CEM。

沿用项目已有门及判据版本：提升≥3cm、旧同时挡停率≥50%、指尖离桌≥0、漂移≤20mm、目标最终不由桌面支撑、无真实桌面阻挡/明显穿透、无缺测。重复通过标准沿用当前 **至少2/3**，同时报告实际是2/3还是3/3，不静默改成3/3门，也不把2/3描述成稳定必成。

补充真实接触一致性检查：左右指分别对目标受力，不能由掌部/桌面接触冒充。它与旧挡停率分列；若旧门PASS但接触证据矛盾，报告判据冲突，不能当真正夹持交付。任何判据语义修复记录criteria版本。

最终选择：**在验收通过者中，取短探针优化奖励R最高者**；同分优先重复通过次数更多、修正更小者。无通过者输出STAGE1_FAIL及三者失败原因，不把最高分失败样本包装为成功。

### S1-D：冻结Stage2输入

保存 `stage1_grasp_recipe.json`：

```text
source_frame, task_grasp_frame, optimized_T, optimized_preload,
actual_control_times, actual_base_commands, actual_q_commands, phase_boundaries,
physics_hash, canonical_state_hash, criteria_revision, verification_results
```

`source_frame`是位姿来源；`task_grasp_frame`是原任务抓取时刻，两者不混用。例如选中F42姿态，不自动把原任务F50闭合时刻改成F42。

recipe保存的是该获胜run的实际执行数组，不能取“最后一次仿真”缓存，更不能只存q终点后让Stage2重生成另一条曲线。

## 2. Stage2：只负责到达这个解并带着物体走，不再搜抓取位姿

### S2-A：一次完整连续复现

固定Stage1交付的T和闭合配方，使用原Stage2时间线：

```text
原参考前缀 → 接近Stage1 anchor → 原样执行闭合recipe → 原参考搬运段
```

同一次仿真内连续执行。**不把Stage1的20cm验证提升拼进Stage2，不在闭合后reset或清零速度，不切换PD/摩擦/碰撞过滤。**

命令衔接必须满足：

- 接近末端到达优化anchor；闭合时基座仍使用该anchor。
- CLOSE/SETTLE/CARRY的q首末点连续，携带沿用已经验证的闭合目标。
- 位姿、时间戳与速度衔接符合同一时间参数化；不靠瞬移或额外保持掩盖不连续。
- 手物参考相对位姿C0取闭合稳定末端，搬运中不随滑移更新。

携带期验收沿用相对位置≤5mm、相对旋转≤5°、规定搬运进度及既有基座跟踪/碰撞有效性门。接近、闭合、携带分别输出首个失败点。前0.5s可作为早停诊断窗口，但交付必须完成整个Stage2段，不能以0.5s成功代替全段成功。

### S2-B：失败只修失败阶段

| 首个失败相位 | 允许的下一步 | 禁止做的事 |
|---|---|---|
| 接近碰撞/未到位 | 固定anchor和闭合，只修接近路径 | 不重新优化Stage1抓取位姿 |
| 到位后夹不住 | 对比Stage1/2实际T、q、速度、物体状态和profile；先修差异 | 不先用增加摩擦或深闭合补偿调用不一致 |
| 起步或搬运滑落 | 检查接触载荷、相对位姿和参考加速度；报告动力学失效 | 不把任务失败改名为接近问题，不偷偷放宽5mm/5° |
| Stage2全部通过 | 冻结这条时间线，交给Stage3连续执行 | 不重新生成前缀 |

接近确实需要优化时，只有一个固定的局部路径模型：

```text
p(u) = p_nominal(u) + 64*u³*(1-u)³ * a,  u∈[0,1]
a = [ax,ay,az]（world坐标），每轴±3mm
```

偏移及其前两阶导数在端点为0，**不改接近起终点及其边界速度**；基准路径本身须先连到anchor。旋转沿用原有连续插值。优化变量只有a，不包括anchor、摩擦或q。

若执行此修正，仍用有界L-BFGS-B、数值差分和同一物理场景；最多60次接近段仿真，计数包括梯度与线搜索，不调用CEM。目标为：

```text
J_approach = 4*mean_preclose ρ(I_unwanted/(m*g*Δt_control))
             + 2*ρ(position_error_at_close/2mm)
             + 2*ρ(rotation_error_at_close/2deg)
             + 0.05*||a/3mm||²
```

I_unwanted为闭合开始前夹爪对目标、桌面和非目标障碍的非期望接触冲量模长之和；不包含正常物体—桌面支撑。m取本次固定目标质量，仅作归一化。硬碰撞/缺测依旧不可交付；全无接触且跟踪正常时该项可能平坦，无需启动优化。原地就位误差不是碰撞路径的问题时，先修执行器，不运行此优化。

找到可行接近后必须重新跑完整S2-A。超过预算或无可靠梯度时停止并报告，不自动扩大路径范围或重开Stage1。Stage2本版也不默认联合优化整条长轨迹。

## 3. 奖励与梯度：一套连续分数，成功另验收

### 3.1 直接使用SAPIEN观测

每个physics子步在 `scene.step()` 后采集接触。按真实body身份分别统计左指—目标、右指—目标、掌部—目标、夹爪—桌面、目标—桌面。读 `point.normal/impulse/separation/position`；存在contact记录不等于已承载。

控制周期法向力为该周期法向冲量之和除整个周期时长；两指同时接触比例必须是**同一子步交集**，不能取两指各自比例的min。掌部接触不能置两指True。原始冲量保留，非零判定仅用固定的数值噪声容差，不以“距离小于5mm”代替接触。

当前 `get_target_contact_report` 和旧reward仍需按上述语义核对；不能因为已经有同名字段就直接拿来优化。物理和采样器问题先在一个固定候选上修通，不扩大为另一轮位姿搜索。

### 3.2 S1-A筛选与S1-B精修共用的公式

以下为本版实施定义，不声称已经接入现有reward：

```text
ρ(x) = sqrt(1+x²)-1
W = 3cm短探针的LIFT+HOLD；H = 最后0.3s保持
C(t) = inverse(T_world_gripper(t)) @ T_world_object(t)
C0 = SETTLE末端的固定相对位姿
Ns = m*g/2

J_rel = mean_W[
  ρ(||translation(C(t))-translation(C0)||/5mm)
  + ρ(||R(C0)^T*R(C(t))-I||_F/(sqrt(2)*5deg_in_rad))
]
J_lift = mean_W ρ((z_obj(t)-z_obj_initial-h_command(t))/30mm)
J_contact = mean_W[exp(-N_left/Ns)+exp(-N_right/Ns)]/2
J_table = mean_H ρ(F_table_on_target_up/(m*g))
J_delta = ||Δp/3mm||² + ||Δθ/(sqrt(3)*1deg)||² + (δq/2mm)²

J = 4*J_rel + 2*J_lift + J_contact + 2*J_table + 0.05*J_delta
R = -J
```

N_left/right为对目标的周期平均法向力；F_table为桌面对目标的向上支撑力，按目标受力方向统一符号。Ns只是尺度，不是夹住的判定阈值。h_command来自固定短提升曲线，不能用实际物体运动反算目标。

筛选时Δp=Δθ=0、δq=1mm；优化时修正相对各自源帧计算。h_command、时间窗、权重和物理配置不变，因此优化前后R可比较。闭合模板可能因帧而不同，但所有帧采用相同控制规则和提升任务，按时间均值归一。

**R不包含成功+100、tier跳变、距离代理或无接触时回退另一套分数。** 物理无效样本单独mask，成功由S1-C决定。优化器显示converged、R最高、接触力较大，都不能单独认定抓取成功。

### 3.3 数值梯度与固定开销

参数归一化为：

```text
u = [Δp/1mm, Δθ/1deg, δq/1mm]
g_j ≈ [J(u+h_j*e_j)-J(u-h_j*e_j)]/(2*h_j)
h = [0.25,0.25,0.25,0.10,0.10,0.10,0.10]
```

即平移扰动±0.25mm、旋转±0.1°、预紧±0.1mm。边界附近用合法单边差分或缩小步长，不能跨越关节/任务边界。全部扰动独立reset到同一规范状态，固定物理参数、驱动目标模板、时长和随机种子，不复用前次仿真末状态。

当前SAPIEN调用链没有提供可用的动力学Jacobian，所以这是**有限差分，不是自动微分**。外部损失连续也不保证接触求解过程处处光滑。先对同点重复3次并对关键方向比较h/2h，差分变化须高于重复噪声且方向基本一致；不可靠则保留初值与最好有效解、结束该初值，**不自动切换CEM/网格/别的搜索流程**。

```python
result = scipy.optimize.minimize(
    objective, u0, method="L-BFGS-B",
    jac=finite_difference_gradient, bounds=normalized_bounds,
    options={"maxiter": 5, "maxls": 4, "maxcor": 3,
             "ftol": 1e-4, "gtol": 1e-3},
)
```

每个初值最多 **96次短探针物理调用**，包括重复性检查、梯度、线搜索和失败调用。七维中心差分一次梯度要额外14次仿真；不能把5次迭代说成5次仿真。底层rollout硬计数，超预算返回最好有效解，不只依赖优化器maxfun。[SciPy L-BFGS-B选项说明](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-lbfgsb.html)

无效样本不得进入中心差分；线搜索如需有限数值可使用固定大代价并保留invalid标志，不能把该哨兵值当真实梯度。缓存必须包含参数、初值、物理/时序/状态版本，不能把小扰动四舍五入成同一点；重复性检查不走缓存。

本版Stage1最坏上限是21次筛选+3×96次短探针+最多9次完整复验。**这是上限，不是必须跑满；梯度法并不保证比上一版少量预紧对照更快。** 先计时单次短探针再报告预算预计耗时，不默认渲染每次试验。

## 4. 物理配置只固定一次，不与位姿一起优化

- 保持当前原尺度、CoACD和真实桌面；重力、夹爪—桌面碰撞开启，不垫高或放大物体。
- 质量、惯量、COM读取实际值后冻结；不在候选之间更改密度。
- 建议基线沿用480Hz/30Hz/16子步，shape contact/rest offset=1mm/0，求解迭代16/1；设置到真实对象并读回。
- 目标恢复系数0，linear/angular damping=0.5/1.0；夹爪、桌面材料恢复系数同样读回。
- 手指PD沿用K=1000、D=200、每指10N上限；预紧优化改变实际闭合目标，不把10N当作实际夹持力。

“位姿近但没抓住”时先看三类证据：两指是否真正碰到目标、实际命令是否一致执行、已接触后是否滑移/挤出。只有第三类且前两类可信，才有依据重点查夹持载荷、摩擦、惯量或运动加速度。诊断到这里不自动开启参数扫描，而是报告明确原因。

#### A. K×位置误差被误当接触力，导致尚未夹住就冻结闭合【最高优先级】

位置：`stage1_grasp_mixin.py:2338–2376`、`:2430–2450`。

当前用 `K * abs(q_command - q_actual)` 得到“力”，两指都超过0.5N就与真实接触判据做OR；连续3点后冻结。这里至少有三个错误：绝对值丢掉张开/闭合方向；运动跟踪滞后也产生误差；该值既未包含阻尼项/限幅，也不是目标物的接触测量。

可复查记录：`output/cc16/stage3/grasp.log:20289–20294`，01:09:08：

```text

finger2: joint2, idx=7, target=0.03000, actual=0.03009
双侧接触确认 → 冻结q=0.0295
触发源=KΔq>阈值；sep=(12.1367mm,None)；n_force=(0,0)
所谓F=(28.996,0.771)N
```

第一指此时主要是“要求张开但没有张开”，不是已经测得约29N夹持力。配置的每指10N驱动上限也说明不能把这个未限幅弹性项直接称为实际驱动力。该窗口原始目标接触冲量为0，第二指没有相应接触证据；**“双侧确认”不成立**。

修改要求：

- 从闭合状态切换、奖励、成功门中删除`_bil_force`这个KΔq兜底；跟踪误差只作为带符号的执行器诊断。
- 不改成另一个“sep<1mm即可确认”的兜底。控制器只用**当前控制周期、同一子步、左右指各自对目标**的实际受力证据；累计`n_force>0`和历史`min_sep`都不能表示现在仍双侧受力。
- 无真实双侧证据时保持有界低速闭合，受行程、时限、单侧推进上限保护；不得假确认后把夹爪停在近全开位置。
- 先出现可测的双侧轻触，才进入有限预紧；不要求预紧之前就达到能承载物重的力，以免形成无法启动的条件。接触信号异常时返回`CONTACT_OBSERVATION_INVALID`，不偷偷用KΔq替代。

#### E. 同时接触比例和力的时间窗口仍不一致

- 当前`bilateral_force_ratio=min(left_ratio,right_ratio)`不是真正同时率。例如左指只在前半段受力、右指只在后半段受力，该式得到0.5，真正交集为0。
- 接触感知日志把自窗口开始累计的`sum_imp_raw`除以固定1/30秒，会在非零时高估均力。报告函数里的`sum_imp/(substeps*dt)`则是窗口均力，二者口径不能混用。

统一规定：每子步保存两指接触布尔值；交集计数除同一窗口子步总数。控制周期力用**该周期新增冲量 / 该周期真实时长**，相位均力用相位总冲量/相位时长。不要在相位内累计，却按单帧时长计算。缺测为UNKNOWN，正常采样且无接触才是0。

### 7.3 cc16历史异常：第一指为何一直在0？用一个隔离检查确定方向

9月25日晚复核：t2j已有两指从0.030m正常闭合的记录，不能把此历史现象描述为全部当前rollout的共同根因。下面的隔离检查仅在当前revision仍出现张不开/跟踪异常时执行，不无条件再跑一遍旧Stage1。

日志确认了异常，**没有确认根因**。同一时段接触列表还出现第一指—ground，因此桌面阻挡是需要核实的线索；也可能涉及关节驱动、碰撞过滤或初始化。按名字打印对了，不等于运动链路已经正确；也不能仅凭它停在0就断言下标错误。

不再换几十个位姿。用当前真实夹爪URDF、同一姿态和驱动，做一次**远离所有外物的空载开合**：两指从合法状态按≤5mm/s执行`0.01 → 0.03 → 0.01m`，每个端点保持0.5s，输出q_cmd/q_actual/dq、驱动读回和全部碰撞对。诊断要求两指均能双向移动，末端跟踪误差≤0.5mm；这是执行器自检容差，不是抓取接触阈值。

- 空载仍停0：先查关节limits、drive target是否被后续覆盖、自碰撞、qpos映射/模式；不能增加摩擦补偿。
- 空载正常、原候选异常：恢复原任务桌面/物体，按子步定位首次停止时的接触对和指形。被桌面挡住则报告`TABLE_BLOCKED`，被目标挡住则保留目标受力证据；二者不能混算。
- 空载仅起步迟滞：先等待实际开放就位再开始闭合；等待有超时，超时算初始化失败。不能用名义开放q假设实际已经开放。

空载场景只是隔离诊断，不抬高正式任务物体、不关闭正式验收桌面碰撞。若确认真实指形在规定局部范围内确实无法形成双侧接触，再做一次几何可达性核查；那时才有依据讨论改任务或夹爪，而不是继续搜奖励。

### 7.4 SAPIEN接触怎么用；奖励这次改什么、不改什么

**可以直接用SAPIEN物理接触，但contact列表不等于已经夹紧。** PhysX允许在几何仍分离时生成接触点，生成接触点也不意味着已有显著冲量；生成距离由两个shape的contact offset之和决定。故本次“列表有接触但冲量为零”本身不能证明引擎失效，也不能用距离阈值把它升级为承载。[PhysX接触生成说明](https://nvidia-omniverse.github.io/PhysX/physx/5.1.1/docs/AdvancedCollisionDetection.html#tuning-shape-collision-behavior)

观测按第3.1节实现：在每个真实physics step之后取body对、normal、impulse、separation。法向分量采用经过方向约定验证的`abs(dot(impulse, unit_normal))`，不能把含切向分量的冲量模长冒充法向力。空载应无目标力；醒着的静置盒在稳定窗口中桌面向上总冲量/时长应约为mg，用它核对采样时机、单位、body归因和睡眠行为。若睡眠时不报告冲量，必须区分“无回报”与“不受支撑”，不得改用伪力填补。

本轮**不改第3.2节奖励权重**，先修数据来源：

- `J_contact`的左右法向力只能来自上述真实目标接触；不输入KΔq，不输入掌部/桌面载荷，不输入错误时间窗口的力。
- `J_lift/J_rel/J_table`继续评价实际抬升、滑移和脱桌；没有抬起不能凭“大力”获得成功身份。
- profile无效、接触观测失效、开放未就位属于INVALID，不拿异常轨迹参与top3或有限差分；采样正常但没碰到属于有效失败，保留连续评分。
- `Ns=mg/2`只是原奖励的归一化尺度，不是“每指达到这个力就一定夹住”的物理定律。确有双侧受力后才分析摩擦承载：仅在近似对称水平侧夹、缓慢竖直提升时，可用`μ_eff*(N_left+N_right) ≥ m*g`作必要载荷核查，不能代替接触方向、力矩平衡和实测滑移。

如果上述链路修好后确实“有双侧受力但一抬就滑”，再按实际法向力、材料组合得到的有效摩擦、物体相对速度和提升加速度分类；如果“一碰就飞”，先查首次接触前的穿透、相位命令跳变、接触法向/冲量和恢复系数。两者都不先开启位姿重优化或摩擦扫描。

代码在`dot(new_support,direction)<0`时直接返回当前simplex最近点距离：找到分离方向只证明不相交，不证明距离已经收敛；当前反例提前退出，保留了角点距离。`_closest()`也只处理1/2/3点，未完成一般三维四面体simplex处理，异常最终可能被吞成None。

**反例B：把CoACD所有分片拼起来交给一次支撑函数，会把凹槽填实。** 当前`_HV=np.concatenate(hulls)`后计算的是全部顶点的凸包，不是引擎里的凸包并集。

```text
目标两个分离凸包：x=[-30,-20]及[20,30]，各自y=z=[-5,5]
两指分别位于空隙：x=[-5,-3]及[3,5]，各自y=z=[-2,2]
真实最近距离：两侧均15mm
当前原函数：asym=0、dmin=0，并置surface_intersect=True
```

**修改要求：**

- 首先修正40mm测试的解析期望值；禁止为使回归变绿修改正确的几何答案。距离实现应有距离收敛条件、完整3D simplex处理、退化/迭代上限状态；超时或缺测返回INVALID，不能把未收敛值称为真值。
- 对每个finger collision shape与每个target CoACD hull分别求距离，再取最小值；保留产生最小值的shape ID、左右各自距离及最近点，不能先把分片合成凸包。手指若有多个shape同样保留分片。
- 碰撞顶点读取核对body pose、shape local pose及实际mesh scale。当前`_coacd_world_hulls()`仅应用actor变换，未显式应用shape local pose；本次未证明d5的shape局部变换非单位，所以这是必须补测的路径，不宣称已经造成d5偏差。
- 接触、穿透、分离、数值失败分开记录；距离为0既可能刚好接触也可能重叠，不能直接等于“穿透”或“好抓取”。当前`asym=|d1-d2|`只是无符号最近距离差，不是有方向的横向中心偏移，也不能据此唯一确定平移方向。
- 新回归至少覆盖：解析盒间隙0/3/5/10/20/40mm、已知非对称间隙、共同旋转/平移后距离不变、上述分片空隙、非单位shape pose、穿透和退化输入；增加与独立距离实现/解析真值的对照。校准不依赖同一错误函数生成期望值。

**因此d5的5～19mm asym和5～13mm gap尚不能作为已标定的真实偏心/空隙。** 这不证明全部数值必错，而是不能再用它们排除测量问题。

### 10.3 已确认问题二：“每子步探针”内部仍会漏记和重复记力【P0】

位置：`physics_env.py:_probe_substep_ground()`约1320～1373行，Stage1约2772/3381行的消费者。

保持当前dt=1/480s、阈值0.05N，直接向原探针输入一个子步的合成contact记录，得到：

| 每指在同一子步的真实总法向力 | contact拆分 | 当前both_force_steps/substeps | 当前每指avg_force_N | 正确结果 |
|---|---|---|---|---|
| 0.06N | 各1组0.06N | 1/1 | 0.06N | 1/1、0.06N |
| 0.06N | 各2组0.03N | 0/1 | 0N | 1/1、0.06N |
| 0.12N | 各2组0.06N | 2/1 | 0.06N | 1/1、0.12N |

这三个结果由当前函数实际计算，不是猜测。第二例原始冲量通道仍能合计到每指0.06N，但受力布尔值及avg_force_N丢失；第三例双侧比例达到2。

原因及修订：

1. **阈值作用位置错。** 当前对每个contact manifold分别判断是否超过阈值，CoACD多shape把同一指力分散后可能全部低于阈值。先按“当前子步、指定finger、指定target”汇总所有shape/contact point的法向冲量，遍历结束后再除dt、判断一次阈值。原始总力不应因低于布尔阈值而丢失。
2. **力累计被布尔去重截断。** `_force_this_step`置True后其他contact的冲量不再进入`sum_imp`。去重只控制受力子步计数，不控制物理冲量总和。
3. **双侧计数仍在`for c in scene.get_contacts()`里面。** 一旦两指标志均True，后面的contact还能再次累加。必须移到整个contact循环结束后，每个物理子步至多+1；对左右/双侧计数全部检查`0 <= count <= substeps`。contact顺序和等效力拆分不应改变结果。
4. **累计窗口不是当前控制周期。** Stage1仍用整段`both_force_steps>0`判“当前双侧”；历史一次有效接触可污染后续多帧。给控制器单独返回本控制周期新增交集子步数/比例；相位统计只用于报告。连续3周期确认必须是三个各自有效的新周期。
5. **采样失败仍可能伪装成零。** `physics_step()`调用探针处仍`except: pass`；法向不可用会回退冲量模长，separation异常会回退0。改为明确valid/error状态，不能未知→0、切向模长→法向力、缺测→贴合。目标按实际body身份绑定，不靠宽松子串相互匹配；活动侧别传入，不隐式依赖默认left。

修完先做拆分/乱序/空窗口/异常输入/左右交替接触的无仿真回归，再做一个已知接触载荷的轻量物理标定。**本次反例证明统计器会出错，但没有证明d5的零受力全部由统计器造成。** 若d5对应子步的原始冲量确实全零，还需核对API采样时机、睡眠、body映射与实际未接触；不能用修统计后预计有力代替验证。

### 10.4 夹持面+闭合轴投影：可作受限诊断，不能宣称适用任何物体/位姿

W4当前使用link原点中点和CoACD顶点均值；后者也不是几何体积质心，会受分片和顶点采样密度影响。换成表面/投影比这两个代理更合理，但有以下边界：

- 两个link原点连线不必等于关节闭合轴。优先从关节轴经FK变换获得世界轴，并用离线小q扰动验证两指沿该轴反向运动；不要因为连线存在就把它命名为真实闭合方向。
- 沿倾斜轴平移会改变世界高度：`Δz = δ * u_z`。W4“只平移不改高度、不会插桌”的注释不成立。每个建议修正都必须重新检查桌面、掌部、目标的间隙及连续接近路径。
- 全部顶点的最内侧极值可能来自指尖、凸起或不参与夹持的区域；目标全局投影极值也可能来自夹持高度之外的把手/凸起。应先确定两侧实际指腹有效区域及对应的目标局部夹持截面/接近深度，再计算投影；不能以全物体投影重叠代替三维包覆。
- 只沿闭合轴平移不能修复指腹与目标在接近轴/高度上的错层、错误姿态、手指行程不足或桌面卡住。投影中线重合不等于双侧接触，双侧接触也不等于可承载。

在上述条件成立时，定义u由左侧指腹指向右侧指腹，使用同一世界坐标系：

```text
l = max(u·p), p属于左指有效内侧面
r = min(u·p), p属于右指有效内侧面
o_min/o_max = 目标局部夹持区域沿u的投影区间
gL = o_min-l,  gR = r-o_max
δ = (o_min+o_max-l-r)/2 = (gL-gR)/2
p_candidate = p_reference + δ*u
```

这里的gL/gR是有方向的轴向间隙，**不是当前GJK无符号最短距离**。实际接触仍用校准后的三维shape距离和物理探针确认。若只提供全物体凸包顶点而无法识别有效夹持区域，上式只能标为“全局包围区间启发式”，不能标为通用真值。

**与原计划统一的边界：** 第1节仍不允许对21个原始帧无条件重新物心对齐。当前`_S1_AUTO_CENTER`默认开启、在rollout内部静默改`target_pos`，与这条约束不一致。下一实现应将它从默认路径撤出，作为固定候选的可开关诊断提案；不得在冻结复验/Stage2重放时再自动对中。正式采用时将δ*u计入已有world每轴±3mm及MANO总偏差预算，不能在±3mm优化之外另送一次无界平移。所需修正超界则报告BOUND_EXCEEDED，不默默扩大。

W4是在初始化/warmup之后又修改target_pos，当前成功日志只说明命令变量变了，不证明新位置已达到、更不证明候选导出了这个新anchor。应用前需明确测量时刻和实际T/q；候选修正、最终下发T、获胜记录和Stage2 anchor必须同源保存。不能只改rollout局部变量而继续交付原始grasp_pose。
