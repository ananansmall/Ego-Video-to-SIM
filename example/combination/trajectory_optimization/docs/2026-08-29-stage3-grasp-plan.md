# Stage3 纯物理夹持改造计划

> 日期: 2026-08-29
> 状态: 计划待实施
> 前置: v6.0 统一物理仿真已完成 (全 stage 纯 PD drive, 参数单一来源, PD 跟踪 0.2mm 实验验证)

## 1. 背景与现状

v6.0 统一物理后 Stage3 实测 (左手 hawor/7, output/gripper_left):

| 指标 | 数值 | 判定 |
|------|------|------|
| lift_peak | 1.91cm | ✗ 未达 3cm |
| lift_final | ≈0 | ✗ 物体滑脱 |
| 恒定距离 | max_dev=33.3mm (tol 5mm) | ✗ |

诊断 (DIAG 日志): 闭合触发在 F42 兜底生效时基座还差 32mm 到位; 手指在下降途中
被物体楔死在全闭 q=0 (fgap=40mm ≪ 物宽 112mm), 夹爪以指尖捏物体边缘, 抬 1.9cm 后滑脱。

根因: 现行"按帧号闭合" (F25-44 边降边闭) 是传送时代的产物 —— 传送下基座严格在轨迹上,
手指与基座天然同步; 纯 PD 下闭合期间基座还以 ~9mm/帧继续下降 8 帧 (~7cm), 手指半路
闭合 → 落在物体肩上 → 被楔死。

对照: Stage1 纯物理成功 (lift 18.41cm, 41N, 160 帧双指接触) 的模式是
**先就位 → 原地闭合**: 手指在物体两侧闭合, 物体把手指撑开 (成功帧 q 被撑到 0.053),
PD 位置误差 × K(1000) ≈ 14N/指 夹持力。

## 2. 不改的部分 (结构确认)

- 轨迹结构保持: F1-37 跟随平移后 MANO → **F38-62 完全继承 Stage2 重建** (锁定,
  不参与优化) → F56-89 smoothstep 逐步回归平移后 MANO → F90+ 纯跟随 (与用户要求一致)
- 物理参数不动: 基座虚拟关节 K=50000/D=600, 手指 K=1000/D=200/限力 100N
  (physics_utils.py 单一来源, 实验验证 0.2mm 稳态误差)
- Stage2 保持确定性最小 jerk 重建 (dz 优化接入管线是独立事项)

## 3. 改造内容 (四步)

### 第一步: 闭合时序重构 — "按帧号" → "到位确认" (核心)

```python
触发 = Δz < 5mm 且 水平误差 < 10mm 且 |vz| < 2mm/帧   # 三条同时满足 = 真正稳定到位
动作 = 原地闭合 10 帧 smoothstep → 0.0393
兜底 = F55 仍未触发 → 打印诊断日志并按原条件闭合 (不静默失败)
```

- 下降全程手指保持全开 (fgap 140mm > 物宽 112mm, 几何上保证可包住)
- 到位后才闭合 → 物体从两侧挡住手指 → PD 误差产生夹持力 (Stage1 模式)
- 废弃"边降边闭像楔子滑入" (传送时代配方, 纯 PD 下导致楔死)

### 第二步: 夹持目标对齐 Stage1

- 现状: `_GRIP_PD_HOLD = best_grasp.qpos(0.0393) - 0.004 = 0.0353` (比 Stage1 深压 4mm;
  "深压 0.004" 是 v4.42 在传送伪影下调的, 作废)
- 改为: 直接用 Stage1 验证值 `0.0393` (Stage1 日志: 物宽 11.18cm, 接触 qpos=0.0473,
  PD_target=0.0393 → 成功抬 18-23cm)
- 原则: 抬升期间**不追加深度** — 手指被物体撑开多少就撑开多少 (q 到 0.05 正常),
  位置误差即夹持力

### 第三步: 后半段开合 MANO 化

1. **开合信号换源**: 从 hand_pose 45 维关节角算手指蜷曲度 (index+middle 关节角模长,
   归一化), 替换当前饱和在 0.05 的 "拇指尖-食指尖距离÷2" (实测全程 17-19.5cm 无信息)
2. **释放帧自动检测**: 蜷曲度从抓取峰值回落拐点 = 放下确认帧 (本数据实测 F60-70),
   替换硬编码 F90-95; 释放 = 8 帧 smoothstep 张开
3. **释放后跟随**: 释放完成后开合完全跟 MANO 蜷曲信号
4. **待用户确认**: curl 数据指向放下在 F60-70, 但该时刻夹爪不在碗 (glb_8) 上方 —
   需确认视频中 toy 的实际放下时刻/位置, 排除 "对齐残差导致半路放下" 的可能

### 第四步: 验收闭环 (参数调好的判据)

三条硬指标, 全过才算达标:

| 指标 | 判据 |
|------|------|
| 恒定距离 | 夹持确认帧→释放帧, \|dist(fmid,obj)−ref\| ≤ 5mm |
| 抬升 | lift_final ≥ 3cm (用终值, 不用峰值 — 中途滑落直接露馅) |
| 释放 | 释放后 10 帧内物体 z 波动 < 2mm (稳定放置, 不弹飞) |

- 全部写入 `[PhysicsValidation][stage3]` 日志
- 同步加入 stage3_reward: 用 "恒定距离罚" 替代现有 lift 阶梯奖 (为启用 CEM 做准备)

## 4. 需调参数汇总

| 参数 | 现值 | 新值 | 依据 |
|------|------|------|------|
| 闭合触发 Δz | <30mm (F42 兜底) | <5mm 且水平<10mm 且 \|vz\|<2mm/帧 | 到位确认 |
| 闭合时长 | 8 帧 | 10 帧 smoothstep | Stage1 用 20 帧 (原地), 折中 |
| hold 目标 | 0.0353 | 0.0393 | Stage1 验证配方 |
| 释放窗口 | F90-95 硬编码 | curl 回落拐点 (实测 F60-70) | MANO 参数驱动 |
| 释放时长 | 6 帧 | 8 帧 smoothstep | 平滑无跳变 |

## 5. 预期风险

1. 原地闭合时夹爪水平未对准 → 指尖碰倒物体 — 触发条件的水平 10mm 门槛挡
2. 释放提前到 F60-70 后物体半路放下 (不在碗里) — 若视频确认应放碗中, 则暴露
   MANO 对齐残差问题, 需单独修 (pre_translate 只吸收 F50 处误差)
3. curl→开合映射需标定: 抓取帧 curl 峰值 ↔ 0.0393, 最松帧 ↔ GRIPPER_MAX_OPEN,
   用本数据自动标定

## 6. 迭代方式

每轮运行完整 v4 管线 (~3.5 min), 只看三条硬指标; 预计 2-3 轮收敛。
