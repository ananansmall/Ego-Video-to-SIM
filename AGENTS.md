## Code Graph Skills

This project has two code knowledge systems:

1. **graphify** — knowledge graph at `graphify-out/`. When the user types `/graphify`, use the installed graphify skill.
2. **code-graph-llm** — code graph at `llm-code-graph.md` and project memory at `llm-agent-project-learnings.md`.

For full behavior rules (ProjectMap, Reflections, ThinkBeforeCoding, Simplicity, SurgicalChanges, GoalDriven, FreshDeps, ContextBudget), refer to `.trae/skills/code-graph/SKILL.md` and `.trae/skills/graphify/SKILL.md`.
