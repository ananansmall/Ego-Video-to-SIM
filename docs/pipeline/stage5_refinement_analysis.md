## 一、问题背景

121 场景 Stage 5.2 穿模迭代跑满 **8 轮耗时 ~550s**，日志显示同样的穿模对反复出现（分离距离恒定 0.1006m），收敛条件永远达不到。最终结果正确（check_stability 兜底），但过程大量空转。

```
改前链路（事实上的执行路径）:
VLM判correct → SP贴合被跳过 → 子物体嵌在桌体内
→ 穿模模块被迫用毫米级FCL深度+固定余量反复推挤(8轮)
→ check_stability 大幅修正(+0.39~+0.87m)兜底出正确结果
```

## 二、排查过程与根因链

诊断工具 `tools/diagnose_penetration.py`（深拷贝上仿真，不影响输出）逐层定位：

### 根因 1：穿模深度被余量放大成假象
真实 FCL 穿模深度只有 **0.6~5.1mm**，但日志显示"0.10m 分离"。解码后发现 `sep_dist = pen_depth + 尺寸阶梯余量`（大物体 +10cm），毫米级触碰触发 10cm 瞬移。

### 根因 2：方向可以朝下
方向由两物体**中心 z 比较**决定。bowl_0 中心 0.497 < 斜桌中心 0.534 → 被往下推，8 轮从 0.50m 沉到 0.06m 贴地板，越推越穿。

### 根因 3：SP 被投影法错误锚定（最深层的病根）
`sp_refine_on_top` 的投影法支撑面估计（L694-L717）有隐含假设：

```python
below = supporter_vertices[:, 2] <= supported_bottom_z   # 只找低于物体底面的点
```

物体**嵌得越深，算法越确信表面就在脚底下**——它永远无法发现比自己高的表面。铁证：同一张桌子，8 个物体拿到 supporter_top=0.18~0.24（投影法锚定到桌腿），唯独 mug_1 因 xy 范围内无匹配点走了 fallback bbox 分支拿到真实的 0.876。

### 根因 4：VLM 程度判断看的是真实照片
`optimal_frames/*.jpg` 是输入视频原始帧，照片里物体本来就摆对了 → VLM 永远返回 `correct` → SP 贴合从未实际执行。VLM 的语义职责没问题（关系确实对），缺的是几何摆放校验。

## 三、修复清单（全部在 refine_inter_object_placement.py）

## 四、Stage 5 完整管线逻辑（当前版本）

```
输入: all_instances.pkl + relations_scene_graph.json
──────────────────────────────────────────────────────────
 5.1 场景图关系推断   VLM看真实照片投票 → X supported by Y
 5.2 ① 基础精修      floor/wall/embedded 位姿+贴地
     ② SP精修       按关系把子物体放到支撑面（修复核心）
     ③ 穿模迭代      全局几何互斥消解
     ④ check_stability  位姿转正+落座收尾
──────────────────────────────────────────────────────────
输出: final_scene_stage5.glb
```

### 5.1 场景图关系推断（未改动）
全场景预览 1 次 + 每实例多帧投票确定支撑关系；物理常识后处理。只定语义，不动 mesh。

### 5.2-① 基础精修（第一道位姿调整）
`sp_refinement.py::refine_supported_by_floor_object`：
- 重力轴旋转对齐：倾角 <10° 或 >170° 才做，**死区 [10°,170°] 不动**（防斜靠物误转）
- z 落地贴合：|z_min| < 0.3m 才做

代价：121 场景两桌 41°/21° 卡死区，带斜进入后续环节。

### 5.2-② SP 精修（关系驱动放置）
```
VLM判correct → 几何校验(A): 嵌入>5cm? ─ 否 → 跳过
                                     └ 是 → 完整z轴贴合
支撑面高度计算(E): 深嵌 → bbox顶; 正常 → 投影法(脚下实际表面,规避斜桌bbox虚高)
贴合: 底面对齐支撑面顶(+offset); minor档限幅0.15m
```

### 5.2-③ 穿模迭代
每轮全对重扫 `AABB预筛 → FCL接触 → 当场修`：

| 对类型 | 处理 | 单次位移 |
|--------|------|---------|
| floor/wall 参与 | 对方动 | — |
| 小↔大跨层 | 小物体 z-only，方向必向上(B)，嵌入一步到位(C) | 一次到位 |
| 大↔大同层 | 共享互退+层级跟随 | 各退一半 |
| 小↔小水平挤压(F) | 互退平移 | 各退 (深度+5mm)/2 |
| 小↔小 z叠置 | 上方物体垂直微调 | 深度+5mm |

出口三选一先到先停：零穿模 ✅ / 对数不降兜底(D) / 8轮上限。

### 5.2-④ check_stability（位姿+位置收尾，未改动）
| Phase | 内容 |
|-------|------|
| P1 | floor 类旋转对齐（阈值宽 >1° 即转）+贴地 |
| P2 | 其余物体旋转对齐+悬空落到支撑顶 |
| P3 | 接触比<20% → z修正贴实表面 |
| P4 | 统计输出 |

### 位姿调整职责总表
| 环节 | 阈值 | 设计意图 |
|------|------|---------|
| 基础精修 | <10°/>170° 且 \|z_min\|<0.3 | 小偏差顺手修，大倾角不敢碰 |
| check_stability P1/P2 | >1° 全转 | 最终兜底保证正立输出 |

## 六、否决的方案

**--pre-upright 预转正实验**：把基础精修的旋转对齐提前（消除倾斜桌 bbox≠表面问题）。实测否决：
1. 转正改变占地轮廓，两桌变垂直互穿（穿模对数 2→9 反增）
2. 投影法自指问题不因此解决（子物体仍被锚定在低处）

保留为诊断开关，不进管线。

## 七、遗留观察项（未处理）

1. **几何校验与 sp_refine_on_top 的支撑面数值不一致**（116 日志：0.9423 vs 0.4444），值得统一计算口径
2. cabinet_2 倾角 168.8°，距基础精修 >170° 翻转门槛差 1.2°，卡死区边缘
3. Stage 3 对齐无重力约束 → 全员带 6°~41° 倾斜入场（上游问题，本阶段不修）
4. 倾斜桌场景下 SP 贴的是 bbox 顶而非真实表面，中间态悬浮 ~0.18m 由 Phase3 归位（终点正确，路径有绕）
